# AccordLegacy

A fork of [Gramophone](https://github.com/AkaneTan/Gramophone) / [AccordLegacy](https://github.com/FoedusProgramme/AccordLegacy) with bug fixes, updated dependencies, and new features.

## Installation

Download the latest APK from [GitHub Releases](https://github.com/emylfy/AccordLegacy/releases/latest).

## Building

```bash
git clone https://github.com/emylfy/AccordLegacy.git
cd AccordLegacy
./gradlew assembleRelease
```

APK will be in `app/build/outputs/apk/release/`.
